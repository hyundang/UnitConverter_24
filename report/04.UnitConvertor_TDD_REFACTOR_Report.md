## 5. 아키텍처·설계 (REFACTOR 결과)

### 5.1 레이어 의존 (ECB)

```text
cli.py
  → application (process_stdin_lines, format_csv/format_table, parsing)
  → domain (validate_unit — cli에서 catch만)
  → infrastructure (load_registry)
application/formatting/output.py  ← FR-4 (JSON/CSV/table 문자열)
application/use_cases.py          ← stdin orchestration
application/parsing.py            ← 파싱·등록 문자열
domain/                           ← 검증·변환·registry
```

| 금지 | 준수 |
|------|------|
| domain → application/infrastructure/cli | ✅ |
| cli 변환 계수 리터럴 | ✅ |
| REFACTOR 중 동작 변경 | ✅ |

### 5.2 `cli.py` 최종 역할 (~62줄)

- argparse · stdin 수집 · `process_stdin_lines` 호출
- `FormatError` / `NumberError` / `UnknownUnitError` → stderr + exit 1
- `_render_output` + print (I/O만)

### 5.3 REFACTOR 후 `src/` 트리

```text
src/
  application/
    formatting/
      output.py       # format_csv, format_table (FR-4)
    parsing.py        # parse_unit_value, parse_register_unit + helpers
    use_cases.py      # register_unit_from_string, process_stdin_lines
  domain/
    constants.py
    conversion.py
    registry.py
    validation.py
  infrastructure/
    config_loader.py
  cli.py
```
