## 1. 요약

UnitConverter_24 프로젝트의 **Logic Track(D-01~D-10)** 과 **UI Track(D-07~D-09, U-01~U-04)** 에 대해 **총 15개 RED 테스트**를 작성·실행했다. `src/` 프로덕션 코드는 의도적으로 미구현 상태이며, pytest는 **8 error + 7 failed**, **skip 0**으로 RED 완료 조건을 충족한다.

**핵심 성과**
- PRD Test Loop 매트릭스(§8.1 S1·S2, §8.2 FR-4~6, §9 사용자 시나리오)를 **D-*/U-* ID**로 1:1 매핑
- 레이어별 SRP 준수: application(파싱)·domain(검증·변환)·infrastructure(설정)·cli(I/O)
- Harness 안정화: `--continue-on-collection-errors`, `tests/test_cli/` 경로 정리

**다음 단계:** GREEN — `src/domain` → `application` → `infrastructure` → `cli` 최소 구현.

## 4. Harness 변경 사항

### 4.1 신규·수정 파일

| 경로 | 역할 |
|------|------|
| `tests/inputs.py` | README 비율·PRD 입력·FR-5·S3 mock·U-* SSOT |
| `tests/conftest.py` | registry·cli subprocess·JSON·cubit·fathom fixtures |
| `tests/__init__.py` | 패키지 정리 |
| `tests/domain/test_d_01.py` 등 | Logic·UI RED TC 15건 |
| `pytest.ini` | `prd_s4` 마커, `--continue-on-collection-errors` |

### 4.2 pytest 설정

```ini
addopts = -ra --continue-on-collection-errors
markers =
    prd_s1 … prd_s4
```

**`--continue-on-collection-errors` 도입 이유:** Logic TC의 ImportError가 전체 세션을 중단시켜 UI TC가 실행되지 않던 문제 해결.

### 4.3 `tests/cli` → `tests/test_cli` 리네임

| 이슈 | 조치 |
|------|------|
| `python -m pytest` 시 UI 테스트 미실행 | Logic 수집 ERROR 시에도 UI TC 실행 허용 |
| `tests/cli/` vs `src/cli.py` 이름 충돌 위험 | `tests/test_cli/`로 이동 (reference.md UI Track 정렬) |
